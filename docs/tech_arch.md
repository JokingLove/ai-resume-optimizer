# AI简历优化产品 - 技术架构文档 v2.0

> **版本**: 2.0
> **日期**: 2026-05-16
> **变更**: 放弃本地模型，改为调用在线AI API

---

## 1. 核心原则

**不跑本地模型，所有AI能力通过API调用实现。**
- 简历解析 → 调用 LLM API（提取结构化信息）
- 岗位解析 → 调用 LLM API（提取关键要求）
- 匹配分析 → 调用 LLM API（语义对比+评分）
- 优化建议 → 调用 LLM API（生成改进方案）

## 3. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | HTML + CSS + JS | 单页面，无框架依赖 |
| 后端 | Python Flask | 轻量级API服务 |
| AI | DeepSeek API | 调用在线模型，无需本地GPU |
| 部署 | 本地运行 + 内网穿透 | 或部署到云服务器 |

## 4. API 设计

### POST /analyze
```
请求: {
  "resume_text": "简历内容",
  "jd_text": "岗位描述"
}

响应: {
  "success": true,
  "data": {
    "score": 85,
    "keyword_match_rate": 78.5,
    "skills": {
      "matched": ["Python", "Flask"],
      "missing": ["Docker", "K8s"]
    },
    "suggestions": [
      {"type": "keyword", "priority": "high", "title": "...", "description": "..."}
    ],
    "optimized_resume": "优化后的简历文本"
  }
}
```

## 5. LLM 调用策略

### 简历解析 Prompt
```
请解析以下简历，提取：
1. 技能列表（技术技能、工具、语言）
2. 工作年限
3. 教育背景
4. 工作经历（公司、职位、时间、描述）

以JSON格式输出。

简历内容：{resume_text}
```

### 岗位解析 Prompt
```
请解析以下岗位描述，提取：
1. 岗位名称
2. 必备技能
3. 优先技能
4. 任职资格
5. 岗位职责

以JSON格式输出。

岗位描述：{jd_text}
```

### 匹配分析 Prompt
```
请对比以下简历和岗位描述：
1. 计算匹配度分数（0-100）
2. 列出匹配的技能
3. 列出缺失的技能
4. 给出具体的优化建议

简历：{resume_structured}
岗位：{jd_structured}

以JSON格式输出，包含：score, matched_skills, missing_skills, suggestions
```

## 7. 部署方案

1. 本地运行 Flask（端口5002）
2. 使用 frp 或 ngrok 内网穿透
3. 或使用云服务器直接部署

## 8. 风险点

| 风险 | 缓解措施 |
|------|----------|
| API 响应慢 | 设置超时，前端显示加载状态 |
| API 限流 | 添加请求队列，控制并发 |
| 解析不准确 | 多轮 Prompt 优化，添加校验 |
| 成本 | 使用 DeepSeek 等性价比高的API |
